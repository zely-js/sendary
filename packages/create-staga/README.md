# create-staga

Scaffold a new [Staga](https://staga.vercel.app) app.

```bash
yarn create staga my-app
```

You can also run it with npm or pnpm:

```bash
npm create staga@latest my-app
pnpm create staga my-app
```

The app is created in `staga-app` when no directory is provided.

## Options

- `--force`: write the template into a non-empty directory.
