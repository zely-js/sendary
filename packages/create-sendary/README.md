# create-sendary

Scaffold a new [Sendary](https://sendary.vercel.app) app.

```bash
yarn create sendary my-app
```

You can also run it with npm or pnpm:

```bash
npm create sendary@latest my-app
pnpm create sendary my-app
```

The app is created in `sendary-app` when no directory is provided.

## Options

- `--force`: write the template into a non-empty directory.
